# Mod status

Live status cards for my mods, drawn by [baise](https://github.com/KiefBC/baise)
every 15 minutes. The images live on the [`badges`](../../tree/badges) branch; `index.md` there has
the BBCode for each mod's Nexus page.

To update after testing a game patch: edit `build` and `date` in `baise.toml`, or run the
workflow by hand with the mod key and a status.
